# odin-recipes

Este proyecto forma parte del currículo de desarrollo web de **The Odin Project**. Consiste en un sitio web de recetas estructurado completamente en **HTML puro**, diseñado para demostrar habilidades fundamentales de maquetación, organización de archivos y control de versiones. 

Para esta práctica, he elegido la receta definitiva para hacer unos **brownies de chocolate húmedos por dentro y con costra crujiente por fuera**, aplicando una estructura limpia y fácil de navegar.

## 🛠️ Habilidades demostradas
Al finalizar este proyecto, habré puesto en práctica:
* **Estructura Semántica HTML:** Uso correcto de etiquetas (`<h1>`, `<h2>`, `<p>`, `<ul>`, `<ol>`) para organizar el contenido de manera lógica.
* **Gestión de Enlaces:** Conexión fluida entre la página principal de recetas y las páginas secundarias mediante hipervínculos (`<a>`).
* **Optimización y Multimedia:** Inserción y atributos correctos para imágenes (`<img>`) de alta calidad.
* **Control de Versiones:** Flujo de trabajo profesional con Git y GitHub (clonación, commits, ramas y despliegue remoto).

## 📋 Contenido del sitio
* **Índice principal (`index.html`):** La página de bienvenida con el catálogo de recetas disponibles.
* **Página de receta (`recipes/brownies.html`):** Ingredientes detallados, pasos de preparación secuenciales y secretos de cocción.
